# Конвейер выпуска

Пользователь сообщает только тему и формат. Остальные поля заполняют агенты.

## Роли

1. `OPUS_ORCHESTRATOR` принимает тему, выбирает сценарий и создает пакет исследования.
2. `CHATGPT_RESEARCHER` ищет факты, первоисточники и изображения. Он не пишет сценарий и не меняет механику.
3. `OPUS_EDITOR` собирает рабочую деку строго по сценарию и подтвержденным фактам.
4. `RENDERER` создает PNG.
5. `QA` блокирует выпуск при сломанной логике, неподтвержденной цифре или слабом изображении.
6. Пользователь утверждает только итоговые PNG.

## Состояния

`IDEA -> RESEARCH_BRIEF -> RESEARCHED -> SCRIPT_LOCKED -> DECK_BUILT -> QA_PASSED -> USER_APPROVED`

Переход назад обязателен, если следующий этап обнаружил ошибку. Пропуск состояния запрещен.

## Источник истины

- Смысл и порядок кадров: `scenario.md`.
- Факты и цифры: `research.json`.
- Изображения: `assets.json`.
- Текст и координаты: `deck.json`.
- Готовые файлы: `renders/`.

## Карточки людей

Главный участник выпуска про артиста всегда получает рейтинговую карточку по `formats/card-spec.md`. В Золотом мяче победитель получает сезонную золотую карту, финалисты получают мини-карты. В дуэли, квалификации и сравнении каждый участник получает отдельную карту. Изображение артиста подтверждает факт или создает атмосферу, карту оно не заменяет.

В `scenario.md` контракт карточек хранится тремя строками: `card_engine`, `card_holders`, `card_frames`. Допустимы только `rating/echorate.py`, `rating/season.py` и `rating/prime.py`. Другой тип карты требует нового движка и отдельной спеки до начала выпуска.

Агент не заменяет отсутствующий факт догадкой. Он создает блокер с точным запросом, который нужно проверить.

## Минимальный вход пользователя

```json
{
  "topic": "прайм THRILL PILL против VIPERR",
  "format": "дуэль"
}
```

## Пакет исследования

Каждый пункт должен содержать:

- `claim_id`;
- формулировку проверяемого тезиса;
- период, к которому относится тезис;
- допустимые источники;
- уровень обязательности;
- нужное изображение и поисковые запросы.

## Стоп-условия

- Нет источника у цифры.
- Для прайма использованы данные другого года.
- Обложка выдается за портрет.
- Один кадр повторяет функцию предыдущего.
- Вердикт появляется раньше доказательств.
- Исследователь переписал сценарий.
- Редактор добавил героя или тезис от себя.
- Главный участник выпуска показан портретом, обложкой или флагом без карточки.
- На кадре появились ссылки, уверенность модели или служебные комментарии.
