# Айсберг артиста

Формат про то, насколько глубоко зритель знает артиста. Сверху то, что слышали все. Вниз уходит материал, который знают единицы.

Спор в комментах заводится сам: зритель видит свой уровень и пишет, почему он глубже.

## Пять уровней

| Уровень | Название | Что туда идёт |
|---|---|---|
| 1 | ПОВЕРХНОСТЬ | треки, которые знает любой слушатель тиктока |
| 2 | ПОД ВОДОЙ | альбомные треки для тех, кто слушал альбом целиком |
| 3 | ГЛУБИНА | ранние релизы, забытые фиты, снятое с площадок |
| 4 | ДНО | анрелизы, которые ходят по сети, лики, сниппеты |
| 5 | БЕЗДНА | то, что существует только в студийных архивах |

Уровень назначается по узнаваемости. Качество здесь ни при чём. Сильный трек спокойно лежит на дне.

## Данные

Один артист равно один файл в `iceberg/data/`. Схема лежит в `iceberg/schema.json`.

| Поле | Обязательное | Что значит |
|---|---|---|
| `title` | да | название так, как его пишут |
| `type` | да | `release`, `unreleased`, `leak`, `snippet`, `demo`, `feature` |
| `level` | да | от 1 до 5 |
| `year` | нет | год появления, если известен |
| `where` | нет | где это можно услышать |
| `note` | нет | одна строка контекста |

## Глубина артиста

Одно число, которое считает движок и которое выносится на кадр.

```
ГЛУБИНА = сумма(уровень позиции) / количество позиций
```

Значение от 1 до 5. Глубина 1.4 значит, что артист живёт на поверхности. Глубина 3.8 значит, что его знают в основном по анрелизам.

## Кадры

Айсберг рисуется сверху вниз на 1080 на 1440. Ватерлиния проходит между первым и вторым уровнем. Каждый уровень получает свою полосу.

Карточка артиста на первом кадре собирается по `formats/card-spec.md`. В подвал карты вместо цены ставится глубина.

## Что нельзя

- Выдумывать анрелизы. Позиция без подтверждения в файл не попадает.
- Ставить на дно то, что лежит на стримингах.
- Собирать айсберг артисту, у которого меньше десяти позиций. Формат разваливается.
- Писать на кадре, откуда взята позиция. Правило из `formats/card-spec.md` действует и здесь.
