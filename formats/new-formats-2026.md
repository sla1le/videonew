# Семь новых форматов

Каждый формат имеет движок в `rating/formats.py` и возвращает `ready` и `blocked_by`.
Формат со статусом `ready: false` не снимается. Список блокеров это техзадание на сбор данных.

Проверка готовности:

```bash
cd rating && python3 formats.py all
```

## Сводка

| Формат | Готов | Что мешает |
|---|---|---|
| Скрытый потенциал | да | снимается сегодня |
| Трио за 200 млн | да | мало вариантов, нужна большая лига |

| Wonderkids | нет | мало молодых артистов в базе |
| Новички 2026 | нет | в базе нет дебютантов 2025 и 2026 |
| Puskás | нет | нет `rating/data/puskas.json` |

## 1. СКРЫТЫЙ ПОТЕНЦИАЛ

Самый сильный из семи по готовности. Дополнительного сбора данных для базовой версии не требует.

**Формула на кадре**

```
РАЗРЫВ = (ТЕКСТЫ + ЗВУК + ПОДАЧА) / 3 - (ХИТЫ + ВЛИЯНИЕ) / 2
```

Порог 8. Левая часть это ремесло, правая это охват.

**Результат старого расчёта**

| Артист | Ремесло | Охват | Разрыв |
|---|---|---|---|
| LILDRUGHILL | 84.67 | 64.50 | +20.17 |
| KAI ANGEL | 83.33 | 71.50 | +11.83 |
| 9MICE | 82.33 | 72.00 | +10.33 |
| THRILL PILL | 72.67 | 63.00 | +9.67 |
| OG BUDA | 83.00 | 77.50 | +5.50 |
| ЕГОР КРИД | 78.67 | 80.50 | -1.83 |

Перед выпуском таблица пересчитывается текущим движком. Эти числа служат эталоном старого снимка.

**Драматургия.** У Крида в старом расчёте был единственный отрицательный разрыв. Его охват опережал ремесло. Это спорная точка выпуска.

**Структура на 7 слайдов**

1. Заголовок: Кто недополучил своё
2. Формула разрыва
3. Лидер текущего расчёта
4. Два следующих места
5. Порог попадания
6. Самая спорная обратная сторона
7. Вопрос зрителю и призыв

## 2. У ТЕБЯ 200 МЛН

**Осторожно.** Механика трансферной стоимости была отклонена как выдуманная цифра без источника.
Этот формат живёт только потому, что цена стала опубликованной функцией от балла.
Формулу обязательно показывать на кадре. Без неё формат нарушает собственный запрет проекта.

**Формула на кадре**

```
ЦЕНА = 3 * 2^((OVR - 55) / 5) * (1 + (ПОТЕНЦИАЛ - OVR) / 40)
```

Цены всегда пересчитываются из актуальной лиги перед выпуском.

**Проблема механики.** Маленькая лига даёт слишком мало разных составов. Формат становится играбельным после расширения пула.

Целевой размер лиги: минимум 9 артистов.

|---|---|---|---|---|
| СКРИПТОНИТ | 2015 | 90 | 1 | пройден |
| ЛСП | 2017 | 88 | 1 | пройден |
| PHARAOH | 2017 | 87 | 2 | пройден |
| OXXXYMIRON | 2015 | 86 | 3 | пройден |

ЛСП это единственный артист в призах обоих посчитанных сезонов. Это готовый заголовок.

## 4. TOTY РУССКОЙ МУЗЫКИ

Схема 3-3-1. Семь слотов: ST, LW, RW, CAM, CM, CDM, CB.

**Сборная 2017, старый расчёт**

| Слот | Роль | Артист | OVR |
|---|---|---|---|
| ST | хитмейкер | ЭЛДЖЕЙ | 76 |
| LW | эксперимент | PHARAOH | 87 |
| RW | эксперимент | ЛСП | 88 |
| CAM | текстовик | ХАСКИ | 82 |
| CM | связующий | пусто | |
| CDM | продакшн | СКРИПТОНИТ | 85 |
| CB | старая гвардия | 25/17 | 74 |

**Сборная 2015, старый расчёт**

| Слот | Артист | OVR |
|---|---|---|
| ST | НОГГАНО | 71 |
| LW | PHARAOH | 78 |
| RW | ЛСП | 86 |
| CAM | OXXXYMIRON | 86 |
| CM | пусто | |
| CDM | СКРИПТОНИТ | 90 |
| CB | КАСПИЙСКИЙ ГРУЗ | 80 |

**Пустая позиция остаётся пустой.** В обоих сезонах нет ни одного CM.
Затыкать дыру чужим артистом запрещено. Это закреплено тестом `test_toty_no_position_swap`.
Пустой слот сам создаёт повод для комментариев.

**TOTW против TOTM.** Еженедельная сборная требует семи обоснованных баллов каждую неделю. На текущем темпе сбора данных это невыполнимо. Месячная сборная реальна.

## 5. WONDERKIDS

Правило задаёт движок `rating/formats.py`. Возраст и запас потенциала проверяются по актуальной модели.

Формат блокируется, пока в базе мало артистов нужного возраста с подтверждёнными датами рождения.

Блокеры:

1. добавить минимум 5 подходящих молодых артистов
2. закрыть даты рождения источниками
3. пересчитать готовность командой `python3 rating/formats.py all`

**Академия ЭХО сливается сюда.** Два формата про молодых будут мешать друг другу.

## 6. НОВИЧКИ 2026

Правило задаёт движок. Для каждого кандидата нужен подтверждённый дебют и полный набор обязательных источников.

**Блокер.** В базе мало артистов с дебютом 2025 или 2026.

Что нужно: от 6 до 8 артистов дебюта 2025 и 2026, у каждого обязательные источники лигового расчёта.
Без этого движок вернёт `ready: false`.

## 7. МУЗЫКАЛЬНЫЙ PUSKÁS

Награда за один трек. Пять номинантов.

```
БАЛЛ = СУДЕЙСКАЯ ОЦЕНКА * 0.5 + ГОЛОСОВАНИЕ * 0.5
```

**Блокер.** Нет файла `rating/data/puskas.json`.

Формат опасен по двум причинам. Оценка отдельного трека сильно зависит от вкуса. Голосование требует достаточной активной выборки.

На снимке 12 августа у аккаунта 966 подписчиков. Старый порог запуска в 2 000 подписчиков сохраняется как ориентир, но решающей метрикой будет число голосов в обычных опросах.
