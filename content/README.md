# Сценарии

Сценарий считается рабочим, если другой агент может собрать по нему выпуск без творческих догадок.

Обязательные разделы:

1. `Паспорт`
2. `Конфликт`
3. `Правила`
4. `Кадры`
5. `Фактчек`
6. `Ассеты`
7. `Карточки участников`
8. `Вердикт`
9. `CTA`
10. `Запреты`
11. `Критерий отмены`

Гипотеза в сценарии остается гипотезой до результата исследования. Число появляется в деке только после статуса `confirmed`.

Главный участник любого выпуска про людей показывается рейтинговой карточкой. Фото, обложка, кадр клипа и концертный кадр служат доказательством или фоном. Они не заменяют карту.

Раздел `Карточки участников` обязательно содержит три машинно читаемые строки:

```text
- card_engine: rating/prime.py
- card_holders: ИМЯ 1 | ИМЯ 2
- card_frames: 1, 3, 7
```

Допустимые движки: `rating/echorate.py`, `rating/season.py`, `rating/prime.py`. Любой кадр, где артист назван главным героем, содержит его полную карту или мини-карту рядом с доказательством.
