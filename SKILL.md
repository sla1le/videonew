# ECHORATE

## Когда грузить это

Любая задача про канал ЭХО, карточки артистов, рейтинги, золотой мяч, дуэли, деки под вертикальное видео 3:4.

## Порядок работы

1. Прочитать `AGENT_CONTEXT.md`, затем `prompts/master-prompt.md`.
2. Проверить по `formats/formats.md`, кто уже был героем и какой механизм ещё не использовался.
3. Собрать данные и сразу записать источники в `ops/factcheck.md`.
4. Посчитать баллы движком из `rating/`. Вручную формульные статы не выставляются.
5. Сверить результат с `ops/corrections.md`. Там лежат зафиксированные значения БЫЛО, менять их нельзя.
6. Написать тексты кадров по `prompts/style-rules.md`.
7. Сверстать и отрендерить по `build/README.md`.
8. Прогнать `build/qa.py` и посмотреть контактку глазами.
9. Собрать описание по `ops/description.md`. Хештегов 0 или 1.

## Жёсткие границы

Эти вещи не обходятся.

- Длинное тире и эмодзи запрещены в пользовательском тексте и кадрах.
- Запрещённые речевые схемы перечислены в `prompts/style-rules.md`.
- Каждая цифра на кадре имеет источник.
- Каждый выпуск приносит новый механизм или новый способ раскрытия механики.
- Перед выдачей каждый кадр просматривается глазами.

## Карта файлов

| Путь | Когда читать |
|---|---|
| `AGENT_CONTEXT.md` | всегда, первым |
| `prompts/master-prompt.md` | всегда после мастер-контекста |
| `prompts/style-rules.md` | перед написанием текстов |
| `prompts/design-rules.md` | перед вёрсткой |
| `rating/README.md` | перед любым расчётом |
| `build/README.md` | перед сборкой и рендером |
| `build/svg.md` | когда нужны рукописные пометки |
| `formats/formats.md` | когда выбираешь формат выпуска |
| `ops/corrections.md` | всегда перед выдачей |
| `ops/mistakes.md` | когда что-то сломалось |
| `ops/factcheck.md` | когда нужна цифра или дата |
| `ops/analytics.md` | когда решаешь, что снимать дальше |
| `ops/publishing.md` | перед публикацией |
| `ops/backlog.md` | когда нет задачи от автора |

## Среда

Нужны Python 3.11 или новее с Pillow, Node с Playwright, `chromium`, `magick`. Шрифты только с кириллицей: Arial, Arial Black, Impact, Georgia. Oswald, Bebas, Roboto, Montserrat, Inter недоступны.
