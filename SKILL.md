# ECHORATE

## Когда грузить это

Любая задача про канал ЭХО, карточки артистов, рейтинги, золотой мяч, дуэли, деки под вертикальное видео 3:4.

## Порядок работы

1. Прочитать `prompts/master-prompt.md`. Это главный документ, остальное его раскрывает.
2. Прочитать `workflow/README.md` и определить свою роль.
3. Найти утвержденный сценарий в `content/`.
4. Проверить по `formats/formats.md`, кто уже был героем и какой механизм еще не использовался.
5. Исследователь работает по `prompts/chatgpt-researcher.md`. Оркестратор работает по `prompts/opus-orchestrator.md`.
6. Посчитать баллы движком из `rating/`. Вручную цифры не выставляются никогда.
7. Сверить результат с `ops/corrections.md`. Там лежат зафиксированные значения БЫЛО, менять их нельзя.
8. Написать тексты кадров по `prompts/style-rules.md`.
9. Сверстать и отрендерить по `build/README.md`.
10. Прогнать `make check`, затем посмотреть контактку глазами.
11. Отдать готовые PNG на утверждение пользователя.

## Жёсткие границы

Эти вещи не обсуждаются и не обходятся.

- Длинное тире и эмодзи запрещены везде, включая ответы в чате.
- Схемы с отрицанием и разворотом мысли запрещены.
- Каждая цифра на кадре имеет источник.
- Каждый выпуск приносит новый механизм.
- Перед выдачей каждый кадр просматривается глазами.

## Карта файлов

| Путь | Когда читать |
|---|---|
| `prompts/master-prompt.md` | всегда, первым |
| `prompts/style-rules.md` | перед написанием текстов |
| `prompts/design-rules.md` | перед вёрсткой |
| `rating/README.md` | перед любым расчётом |
| `build/README.md` | перед сборкой и рендером |
| `build/svg.md` | когда нужны рукописные пометки |
| `formats/formats.md` | когда выбираешь формат выпуска |
| `ops/corrections.md` | всегда перед выдачей |
| `ops/mistakes.md` | когда что-то сломалось |
| `ops/factcheck.md` | когда нужна цифра или дата |
| `ops/analytics.md` | когда решаешь, что снимать дальше |
| `ops/backlog.md` | когда нет задачи от автора |
| `workflow/README.md` | перед любым новым выпуском |
| `content/` | когда нужен зафиксированный сценарий |
| `prompts/opus-orchestrator.md` | когда роль агента OPUS_ORCHESTRATOR |
| `prompts/chatgpt-researcher.md` | когда роль агента CHATGPT_RESEARCHER |

## Среда

Нужны Python 3 с PIL, Node с playwright, `chromium`, `magick`. Шрифты только с кириллицей: Arial, Arial Black, Impact, Georgia. Oswald, Bebas, Roboto, Montserrat, Inter недоступны.
