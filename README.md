# ECHORATE

Система TikTok-канала ЭХО. Русские рэперы оцениваются как футболисты в FIFA: шесть статов, позиция, общий балл, потенциал.

Канал `@echomgn`, телеграм и лига `@echorate`.

## Быстрый старт

```bash
python3 rating/echorate.py      # посчитать лигу
python3 rating/season.py        # посчитать золотой мяч за год
bash   build/run.sh work gm_    # собрать и отрендерить деку
```

Новому агенту начинать с `AGENT_CONTEXT.md`, потом читать `AGENTS.md` и `prompts/master-prompt.md`.

Перед PR:

```bash
python3 ops/validate_data.py
python3 ops/selfcheck.py
```

## Структура

```text
prompts/   мастер-промпт, правила текста, правила дизайна
rating/    движки расчёта и данные
build/     CSS, генераторы, рендер, QA
formats/   каталог форматов и спеки
ops/       аналитика, коррекции, ошибки, фактчек, публикация
refs/      эталонные кадры и визуальные проверки
iceberg/   схема и данные айсбергов
```

Полная карта репозитория и порядок источников правды лежат в `AGENT_CONTEXT.md`.

## Как считается рейтинг

Шесть статов. Три выставляются вручную и весят в сумме не больше половины: ТЕКСТЫ, ЗВУК, ПОДАЧА. Три считаются формулами:

```text
ХИТЫ     = 70 + 6 * log2(top5 / 60 000 000)
ЛАЙВЫ    = 70 + 5 * log2(cap_eff / 10 000) + min(6, max(0, cities - 5))
ВЛИЯНИЕ  = 70 + 6 * log2(catalog / 300 000 000) + scene

OVR = floor( sum(вес * балл) / 100 + 0.5 )
```

Фестивальная площадка умножается на 0,6. ПОТЕНЦИАЛ никогда не ниже OVR.

Канонические веса и коэффициенты лежат в `rating/data/model.json`. Реализация лежит в `rating/core.py`.

Золотой мяч считается другим движком: единые веса 15 15 15 25 30, лайвы не участвуют, всё строится на рангах того года.

## Жёсткие правила

Каждая цифра имеет источник. Опубликованные значения не переписываются тихо. Лига, сезон и прайм считаются разными движками. Каждый кадр просматривается глазами перед выдачей. Полные правила лежат в профильных спеках, перечисленных в `AGENT_CONTEXT.md`.
