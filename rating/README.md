# Рейтинг

Два разных движка. Путать их нельзя.

| Файл | Зачем |
|---|---|
| `echorate.py` | лига, оценка артиста на сегодня |
| `season.py` | золотой мяч, кто забрал конкретный год |
| `calc_single.py` | шаблон расчёта одного артиста под конкретный выпуск |
| `data/league.json` | результат последнего прогона лиги |
| `data/seasons.json` | результаты сезонов 2015 и 2017 |
| `data/artists.json` | справочник артистов и источников |

## Лига

```bash
python3 echorate.py
```

Массив `A` внутри файла содержит артистов с полями: `T`, `S`, `D` судейские баллы, `top5` сумма пяти лучших треков, `cap` вместимость площадки, `fest` флаг фестиваля, `cities` число городов, `catalog` суммарные прослушивания, `scene` ручная поправка от минус 6 до 6, `form` динамика монтли в процентах, плюс три поля `src_` с источниками.

Без `src_top5`, `src_live` и `src_scene` артиста в массив не добавлять. Цифра без источника в этом проекте не существует.

Два ассерта стоят в коде и срабатывают при любой попытке подкрутить веса:

```python
assert abs(sum(w.values()) - 1.0) < 1e-9
assert w['T'] + w['S'] + w['D'] <= 0.5
```

Второй ассерт важнее первого. Он держит долю субъективной части на уровне половины.

## Сезон

```bash
python3 season.py
```

Пулы задаются списками `p2015` и `p2017`. Поля одного артиста:

```python
{'n': 'SKRIPTONIT', 'pos': 'CDM',
 'T': 84, 'S': 96, 'D': 90,
 'tr': 3,             # место в топ-10 треков, None если нет
 'alb': 1,            # место в топ-10 альбомов
 'vote': 2,           # место в народном голосовании
 'role': 'lead',      # lead, colead, guest
 'spots': [3, 1, 2]}  # все позиции для тайбрейка
```

Пустой `spots` ломал расчёт. В коде стоит защита `sp = a.get('spots') or []`.

Cutoff: все официальные итоги сезона, опубликованные до 31 января следующего года. ЛАЙВЫ в сезон не входят.

## Позиции

ST хитмейкер, CAM текстовик, CM связующий, CDM продакшн, LW и RW эксперимент, CB старая гвардия, REF судья.

Формат REF использовался для выпуска про РЗТ и считался по другим статам:

```
ОХВАТ     = 70 + 6 * log2(подписчики / 300 000)
СТАЖ      = 70 + 8 * log2(лет / 3)
ПРИЗНАНИЕ = 70 + 6 * log2(лайки / 5 000)
```
