# Журнал ошибок

Здесь лежат реальные поломки проекта и рабочие способы лечения.

## Песочница и файлы

### Файловая система откатывается

В одном запуске каталог `/data/skill` потерял большую часть файлов между двумя вызовами. Команды до этого вернули успех.

Лечение: весь цикл сборки держать в одной команде. Конечный артефакт сразу писать наружу, например в GitHub. Не считать `/data` постоянным хранилищем.

### Сеть в песочнице отсутствует

`git push` из терминала не работает. Писать в GitHub через подключённый GitHub MCP.

### Большие файлы

Чтение файлов больше 20 МБ может падать. Для проверки изображения использовать уменьшенную контактку. Архив отдавать через отдельную загрузку файла.

### Чтение файла обрывается на середине строки

`readFile` отдаёт часть файла и пишет `[Truncated after N lines. To continue, call readFile again with offset=N+1.]`. Огрызок после последней полной строки это начало следующей строки, его нужно выбросить. Следующий кусок начинается с этой строки целиком.

Проверено на `build/theme.css`: кусок обрывался на `/* --`, следующий начинался с полного комментария.

Лечение: собирать файл из кусков по номерам строк и сверять размер после записи. Тема легла в 19 290 байт, столько же весит локальная копия.

## GitHub

### 401 при живом статусе подключения

`listUserConnections` показывал ready, реальный вызов возвращал `Failed to connect to MCP server (HTTP 401)`.

Лечение: переподключить GitHub и проверить реальным `listTools`, потом `get_me`.

### 403 на запись

`push_files` и `create_or_update_file` возвращали `Resource not accessible by personal access token`. Повторный вызов позже прошёл.

Лечение: перед объявлением блокера повторить маленькую запись. Тестовый файл `.gitignore` подтвердил доступ.

### 409 при двух записях в одном блоке

```text
409 is at 818d0a7f501fb9ccc45953838ac233ffa3e58239 but expected 416db3730f2dd0ca3b5e6b72230217d8e21e5e35
```

Две записи в один репозиторий из одного блока вызовов гонятся за одну голову ветки.

Лечение: один пуш на блок, sha брать из ответа предыдущего.

### SHA с опечаткой в один символ

```text
SHA mismatch: provided SHA aecd59e5... is stale. Current file SHA is aecd59e2...
```

Файл не менялся, был перепутан один символ. Лечение: копировать sha символ в символ и повторять запись с тем же телом.

### Запись оборвалась на середине

Длинный вызов записи может прерваться. Файл при этом остаётся прежним, потому что запись не дошла до сервера.

Лечение: проверить sha и размер файла, потом повторить запись целиком. Тексты слать обычной кириллицей, escape-последовательности раздувают вызов в три раза.

## Python и генераторы

### Пустой список в `min`

```text
ValueError: min() iterable argument is empty
```

Причина: артист без `spots` в сезонном тайбрейке.

Лечение:

```python
sp = a.get('spots') or []
best = min(sp) if sp else 99
```

### Транзитивная кластеризация

Условие `cur[-1]['raw'] - x['raw'] < 1.0` склеивало цепочку артистов с общим разбросом больше трёх баллов.

Лечение: считать порог от лидера группы.

```python
cur[0]['raw'] - x['raw'] < 1.0
```

### Патч генератора не нашёл строку

```text
AssertionError: ('MISS 02', 0)
```

Лечение: генераторы с кириллицей и большим HTML переписывать целиком. Для точечного патча использовать raw-строки и ассерт `s.count(old) == 1`.

### Экранирование Unicode

В JSON-аргументах литеральный `\uXXXX` требует двойного обратного слеша. В quoted heredoc Python-файла используется один слеш. В `re.sub` replacement с `\u` передавать через lambda.

### Битый символ внутри строки с ошибкой

В `build/gen.py` в сообщении `НЕТ theme.css в папке build` слово оказалось повреждено после серии патчей. Код работал, текст ошибки читался мусором.

Лечение: после патчей кириллических строк перечитывать файл и сверять слова глазами.

## HTML, CSS и Chromium

### Потерянные активы

```text
FAILED file:///.../html/photos/lsp.png net::ERR_FILE_NOT_FOUND
```

Лечение перед каждым рендером:

```bash
rm -rf html/photos html/assets
cp -r photos html/photos
cp -r assets html/assets
```

### Сломанный `font:`

```text
BROKEN SHORTHANDS: ['font:400 52px/1.34']
```

Браузер отбрасывает сокращение без семейства. Использовать отдельные свойства `font-weight`, `font-size`, `line-height`, `font-family`.

### Неверный шрифт потомка

`.fact .t` однажды унаследовал Impact. На всех текстовых потомках указывать `font-family: var(--txt)` явно.

### Переполнение карточки

Контент карточки судьи занимал 1367 пикселей при доступных 1242.

Лечение: `overflow:hidden` на `.card`, потом сократить или уплотнить конкретный блок. Скрытие само по себе проблему не решает, оно только не даёт ей испортить соседний кадр.

### Пустота внутри кадра

Два `margin-top:auto` подряд разрывают вертикальный поток. Гэп больше 110 пикселей внутри тела считается дырой.

Лечение: увеличить высоту фото, padding содержательных строк или добавить один полезный факт. Не заливать пустоту декором.

### Заголовок не помещается

18 символов при 82px Arial Black не влезают в ширину 936px.

Лечение: сократить заголовок или уменьшить размер только на этом кадре. Не ужимать весь проект.

### Средняя точка переносится

Строка с `·` может развалиться пополам. Нужен явный `<br>` в месте переноса.

### Кроп из старой карточки

Обычный кроп 9mice захватил белый фон. Для исходника 1122 на 1402 фото находится в прямоугольнике `332x352+673+84`.

### Chromium шумит

Сообщение `Floss manager not present` обычно не означает падение. Фильтровать строку через `sed '/Floss/d'`. Не добавлять `|| true`, иначе реальная ошибка тоже будет скрыта.

### Неверный инструмент

`connections.computer.terminalWithBrowser` не существует. Использовать обычный terminal и `shot.js`.

## ImageMagick и архивы

Команда `convert` устарела, использовать `magick`.

Zip с кириллицей на Windows иногда показывает битые имена. Создавать через `zipfile`, при необходимости преобразовывать имя `n.encode('cp437').decode('cp866')`.

## Рейтинг и факты

### Перепутаны статы

В карточках Крида и Кая ПОДАЧА и ЛАЙВЫ стояли не на своих местах.

Лечение: единый неизменный порядок в генераторе: ТЕКСТЫ, ЗВУК, ПОДАЧА, ХИТЫ, ЛАЙВЫ, ВЛИЯНИЕ.

### Формула не сходилась

Ранние выпуски показывали итог без воспроизводимого расчёта. Теперь OVR считается только кодом, округление `floor(x + 0.5)`.

### Рейтинг KAI ANGEL менялся

В эволюции был 84, позже 80. Текущий пересчёт даёт 79. Старые 84 сохраняются в поле БЫЛО. В дальнейшем балл почти не меняется без новых данных.

### Сезонный тайбрейк применялся неверно

В ранней версии 2017 тройку пытались переставить общим тайбрейком. По финальной модели группы строятся с порогом 1,0 от якоря-лидера. В 2017 ЛСП первый, PHARAOH второй, Скриптонит третий.

### Temporal leakage

В оценку старого года попадали данные 2026. Теперь сезон использует только официальные итоги, опубликованные до 31 января следующего года.

### ЛАЙВЫ в золотом мяче

Концерты давали Оксимирону лишнее преимущество в 2016. ЛАЙВЫ исключены из SEASON. Старый балл 91 подлежит пересчёту.

### Рейтинг дуэта

Два участника VIPERR нельзя усреднять в одну карточку. Kai Angel и 9mice считаются по отдельности.

### Трек приписан не тому артисту

В сезоне 2018 трек `superchuits` был приписан чужому исполнителю.

Лечение: каждую позицию из итогов года сверять с самой страницей издания. Память источником не считается.

## Дизайн выпуска

### Набросок автора это эталон

Было: дека собрана по своему вкусу, фон заменён, кадры снова чернобелые, список нужных фото не спрошен.

Ответ автора: «у тебя была задача повторить дизайн, собрав факты», «пересобрал нахуй всю деку на отьебись», «не попросил фотки которые тебе нужны для правильной сборки».

Лечение: набросок из репозитория и присланные кадры важнее любых доков и любого вкуса сборщика. Сначала повторяется раскладка наброска, потом в неё подставляются проверенные числа. Список нужных фото спрашивается до сборки.

### Чернобелые кадры возвращались дважды

Правило про цвет портретов записано в журнале правок 9 августа, дека всё равно ушла серой.

Лечение: перед сборкой читать `ops/corrections.md` за последние дни.

### Обложка 236 пикселей

Обложка альбома Boys Don't Cry в пакете лежит размером 236 на 236 и на слоте 460 на 460 мылит.

Лечение: проверять размер исходника до сборки кадра и просить файл крупнее.

### Восьмой кадр съедает половину зрителей

Глубина по снимку 10 августа: семь кадров дают 58,2 процента, восемь дают 51,2.

Лечение: держать шесть или семь кадров. Восьмой ставится только под конкретную причину.

### Доки репозитория устаревают быстрее цифр

`ops/analytics.md` до 10 августа считал рекордом 48 400 просмотров при реальных 132 800 и 489 подписчиков при реальных 799.

Лечение: перед выводами о канале пересчитывать `analytics/report.py` по свежему снимку.

### Новое правило линтера сработало вхолостую

Правило про причину под баллом искало `class="tr` и попадало в `class="tri"`, сетку из трёх фото на обложке.

Лечение: любое новое правило прогонять по всем декам из `build/decks` до пуша.

## Текст

QA уже ловил длинное тире, «не как дуэт, а», «Не артист, а один трек», «а не просто листать». Проверять нужно слайды и ответы в чате.

Фидбэк аудитории, который нельзя забыть:

```text
слишком иишно (
мог бы поделать своими руками, да это было бы хуже выглядело но естественно и полюбому больше бы набрало, оно так и работает
текст 76, поржал
```

Лечение: конкретные факты, рваный ритм, авторское «я», меньше служебного языка. Автоматический фильтр остаётся обязательным.

### Балл без причины читается как выдумка

Комментарий «а нахуя творчество превращать в цифры какие-то ебучие» пришёл на кадр, где стояли шесть баллов и ни одного пояснения.

Лечение: поле `why` у кадра и пояснение у ряда статов. Линтер предупреждает, когда баллы на кадре есть, а причины нет.

## Визуальный QA

Рендер без ошибок ещё не готов. Каждый PNG открыть глазами. Проверить лица, поля, размер текста, иерархию, повтор композиции, число SVG-пометок. Только после этого собирать архив.
