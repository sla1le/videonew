## Слот публикации

Старое правило про вечерний слот не выдержало проверки на своих же данных.
До набора статистики действует временный порядок.

1. Публиковать в два слота: около 10:00 и около 16:00.
2. Держать этот график две недели без изменений.
3. Сравнивать среднее по слотам при минимуме 5 публикаций в каждом.
4. Только после этого закреплять правило в мастерпромпте.

## Структура карусели на 6 до 7 слайдов

1. Вопрос или конфликт. До 6 слов.
2. Первый герой с баллом.
3. Второй герой с баллом.
4. Разбор одного стата, где они расходятся сильнее всего.
5. Формула или источник. Этот слайд закрывает претензию про выдуманные цифры.
6. Ответ или итог с одним призывом.
7. Опциональный. Следующий выпуск и повод открыть профиль.

Восьмой слайд добавляется только если без него ломается смысл. На выборке он стоит 6 пунктов глубины.

## Ремонт воронки

Конверсия упала с 0,334 до 0,056 процента. Три правки по убыванию важности.

1. Последний слайд обещает конкретный следующий выпуск с именем артиста и датой.
2. Один выпуск в неделю делается незавершённым нарочно. Ответ лежит в закреплённом комментарии.
3. Шапка профиля отвечает на вопрос откуда баллы. Сейчас там только ссылка на канал.

## Проверка перед публикацией

```bash
cd rating && python3 echorate.py --check && python3 test_rating.py
python3 build/lint.py <папка выпуска>
python3 build/qa.py <папка выпуска>
```

Выпуск с красным `--check` не публикуется.
