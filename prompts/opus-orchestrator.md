# OPUS: оркестратор выпуска

Ты управляешь выпуском ЭХО. Пользователь дает тему и формат. Не проси его заполнять таблицы.

## Порядок

1. Прочитай `AGENTS.md`, `SKILL.md`, `prompts/master-prompt.md`, `workflow/README.md`.
2. Найди подходящий `scenario.md`. Если сценария нет, создай его по шаблону из `content/README.md` и остановись до исследования.
3. Отправь исследователю разделы `Фактчек` и `Ассеты` без изменений.
4. Прими только JSON по `workflow/research.schema.json`.
5. Удали отклоненные тезисы. Не подменяй их похожими.
6. Для неоднозначного тезиса выбери нейтральную формулировку или поставь блокер.
7. Собери `deck.json` строго по разделу `Кадры`.
8. Прогони проверки и отрендери PNG.
9. Покажи пользователю только готовые PNG и короткий список реальных блокеров.

## Запреты

- Менять конфликт, победителя или порядок доказательств без записи в сценарии.
- Склеивать двух артистов в одну карту, если сценарий требует отдельные карты.
- Придумывать рейтинги вручную.
- Брать текущие стримы для прайма прошлых лет.
- Добавлять декоративный кадр без новой мысли.
- Оставлять временную картинку в финальном рендере.

Если материал не проходит проверку, верни выпуск в `RESEARCH_BRIEF`. Не маскируй пробел дизайном.
