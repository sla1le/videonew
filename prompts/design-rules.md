# Правила дизайна

## Форматы

Дека 1080 на 1440, соотношение 3:4. Карточка 1080 на 1350.

Карточка внутри кадра занимает 70 до 85 процентов ширины. Мельче не читается на телефоне.

Для графиков, timeline, radar, quadrant и сложных сравнений действует
`prompts/visual-system.md`. Этот файл остаётся главным по геометрии кадра,
палитре и типографике.

## Палитра

```css
--bg:   #FFFFFF
--dark: #111111
--grn:  #22A05B
--red:  #D7263D
--g:    #8A8A8A
--ln:   #E4E4E4
--gold: #D4AF37
```

Красный и зелёный только на числах. Суммарно цвет занимает до 5 процентов площади кадра. Фото цветные, чёрно-белый стиль остался в прошлом.

## Шрифты

```css
--disp: 'Arial Black', Impact;   /* заголовки */
--num:  Impact, 'Arial Black';   /* числа */
--txt:  Arial;                   /* текст */
```

Georgia только для акцентной прозы. Для формул Georgia запрещена.

Nimbus Sans Narrow и Noto Sans запрещены навсегда. В среде нет Oswald, Bebas, Roboto, Montserrat, Inter. Попытка их использовать даёт подмену шрифта и сломанный кадр.

Шрифт прописывается явно на текстовых потомках. Был случай, когда `.fact .t` отрисовался Impact вместо Arial.

Сокращённая запись `font:` без семейства отбрасывается браузером целиком. Чекер в `build/qa.py` это ловит.

## Сетка

Отступы кадра `52px 72px 132px`. Подвал прибит к `bottom: 50px`.

Границы ниже взяты прямо из `build/qa.py` версии 6.0. Это единственный источник
правды по геометрии, документация под него подстраивается.

```text
верхняя граница контента   >= 40 px     MIN_TOP
левое поле                 >= 58 px     MIN_LEFT
правое поле                <= 1032 px   MAX_RIGHT
нижняя граница тела        <= 1300 px   FOOTER_BAND 140
максимальный гэп            150 px      MAX_GAP
один нижний разрыв          до 440 px   BOTTOM_BREAK_MAX
шапка начинается до         240 px      HEADER_AIR_UNTIL
высота шапки               <= 520 px    HEADER_AIR_MAX
```

Гэп больше 150 пикселей внутри тела кадра означает дыру. Лечится увеличением высоты фото, увеличением padding блоков или добавлением контента.

Один разрыв ниже линии 700 пикселей (`BOTTOM_BREAK_FROM`) разрешён до 440 пикселей. Это воздух перед подвалом, он нормален. Уплотнять кадр ради него бессмысленно. Второй такой разрыв уже провал.

Чернил на кадре от 6 до 48 процентов. Кадр легче 9 процентов без фото и без большой цифры считается пустым.

Новые SVG-примитивы используют внутреннюю сетку 4 px. Существующие внешние
границы кадра из `build/qa.py` не пересчитываются ради этой сетки.

## Композиция

Один кадр равно одна мысль.

Доминирующий элемент меняется от кадра к кадру. Фото, потом число, потом список, потом карточка. Подряд два одинаковых по структуре кадра читаются как один.

Заголовок до 6 слов. Тело до 20 слов. Максимум 3 числа на кадр.

Заголовок обязан совпадать с числом строк ниже. Заголовок «три причины» при четырёх пунктах это брак.

Графики только от нуля, если у метрики есть естественный ноль. Для рейтинга
ECHORATE допустима шкала 30-99, потому что это границы самой модели.

На сложном кадре максимум два фокусных элемента. Подробный бюджет сложности
по типам лежит в `prompts/visual-system.md`.

## Запрещено на кадре

- Мелкий текст. Его не читают с телефона.
- Аббревиатуры статов. Только полные слова: ТЕКСТЫ, ЗВУК, ПОДАЧА, ХИТЫ, ЛАЙВЫ, ВЛИЯНИЕ.
- Слово `POT`. Пишется `ПОТЕНЦИАЛ`.
- Номера выпусков.
- Служебные капс-капшены с доменами и датами.
- Тени, градиенты и неоновое свечение.
- График, который сообщает меньше простой таблицы.

## Карточка артиста

Порядок статов строго один: ТЕКСТЫ, ЗВУК, ПОДАЧА, ХИТЫ, ЛАЙВЫ, ВЛИЯНИЕ. Однажды ПОД и ЖИВ поменялись местами, это заметил автор.

Ширина полосы стата считается как `(v - 30) / 69 * 100%`.

В подвале карточки только `T.ME/ECHORATE`.

`overflow: hidden` на `.card` обязателен. Без него контент вылезает за рамку.

## Грабли вёрстки

Два `margin-top: auto` подряд рвут кадр.

Перенос строки на средней точке недопустим, нужен явный `<br>`.

Заголовок из 18 символов при 82px Arial Black не влезает в 936px.

Перед рендером копировать активы внутрь каталога `html`, иначе будет `net::ERR_FILE_NOT_FOUND`.

## Обработка фото

```bash
# портрет в карточку
magick src.jpg -modulate 104,108 -resize '406x400^' -gravity north \
  -extent 406x400 +repage -unsharp 0x1+0.7+0 out.png

# квадрат для деки
magick src.jpg -modulate 104,110 -resize '520x520^' -gravity north \
  -extent 520x520 +repage out.png
```

Если портрет режется из готовой карточки 1122 на 1402, точные координаты фото `332x352+673+84`. Произвольный кроп захватывает белый фон.
