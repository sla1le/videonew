# Правила текста

Аудитория пишет в комментариях «текст иишный». Каждый четвёртый зритель видит машину.

## Запрещено абсолютно

| Что | Почему |
|---|---|
| Длинное тире | главный отпечаток машины |
| Эмодзи | то же самое |
| «не X, а Y» | самая узнаваемая схема |
| «X, а не Y» | зеркало предыдущей |
| «не просто» | то же семейство |
| «не только A, но и B» | то же семейство |
| «это не X, это Y» | то же семейство |
| Триады через запятую | искусственный ритм |
| Симметричные рубрики | читается как шаблон |
| Ровный ритм предложений | живой человек так не пишет |
| Корпоративные максимы в конце | пафос без содержания |
| Абстракция без конкретики | нечего проверить |
| Отсутствие «я» | у канала есть автор |

## Стоп-лист фраз

Жёсткий список. Любая из этих фраз в деке или в описании валит сборку,
проверяет `ops/slop.py`.

в современном мире · на сегодняшний день · стоит отметить · важно отметить ·
важно понимать · следует учитывать · необходимо помнить · не секрет ·
подводя итог · в заключение · погрузимся · играет ключевую роль ·
подчёркивает важность · неизгладимый след · поворотный момент ·
краеугольный камень · открывает новые возможности · революционный ·
инновационный · и знаете что · хочешь честно · если откликается ·
но есть нюанс · именно в этом кроется · успешный успех · раскрыть потенциал ·
может похвастаться · в самом сердце · давайте рассмотрим ·
перейдём к следующему · с каждым днём

Мягкий список. Линтер печатает и пропускает, решение за автором.

таким образом · самое интересное · на самом деле · по сути · как известно ·
разумеется · безусловно · разнообразный · потрясающий · уникальный

## Клише соцсетей, которые уже всех раздражают

- «И знаете что?», «Хочешь честно?»
- «Если откликается, ты знаешь, что делать»
- «И вот здесь начинается самое интересное», «но есть нюанс»
- Разбивка каждой фразы отдельным абзацем
- Цепочки предложений по два слова подряд ради ритма
- Метафоры без опоры на опыт
- «Успешный успех», «раскрыть потенциал», «погрузимся»

## Нейрослоп на кадре

Отдельная болезнь. Текст бывает чистый, а кадр всё равно машинный, потому что на нём висит служебная обвязка.

| Что | Почему |
|---|---|
| Строка «ИСТОЧНИК: ...» | зритель листает, сноски он не читает |
| Штамп «ПОДТВЕРЖДЕНО» | кадр начинает выглядеть отчётом |
| Значки уверенности, confidence, проценты точности | то же самое |
| Подпись, откуда взято фото | этого никто не спрашивал |
| Оговорка «данные могут отличаться» | подрывает собственный тезис |
| Уклончивый вердикт | канал существует ради прямого ответа |

Источник проверяется до рендера и живёт в данных. На кадр он не выходит. В описание тоже.

Правило из `ops/factcheck.md` остаётся в силе. Меняется только место, где источник виден. Автору видно в репозитории, зрителю не видно на экране.

Если цифру страшно вынести без оговорки, её не надо выносить вообще. Кадр собирается без неё.

## Канцелярит

Глагол сильнее отглагольного существительного. Увидел слово на «-ание»,
«-ение», «-ация», ищи нормальный глагол.

| Было | Стало |
|---|---|
| осуществление пересчёта баллов | пересчитал баллы |
| произведено сравнение артистов | сравнил артистов |
| наблюдается снижение показателя | показатель упал |

Исключение: названия осей рейтинга. ТЕКСТЫ, ЗВУК, ПОДАЧА, ХИТЫ, ЛАЙВЫ,
ВЛИЯНИЕ остаются как есть, это термины.

## Ритм

Машина пишет предложениями одинаковой длины. Человек скачет.

Правило: в каждом абзаце есть предложение короче восьми слов и есть
предложение длиннее двадцати пяти. Одна только вариация длины уже сильно
меняет ощущение от текста.

Плотность тоже неровная. Удар цифрами, лёгкая связка, личное отступление,
снова удар. Когда каждое предложение несёт одинаковый вес фактов, читается
как отчёт.

## Что делать вместо

Рваный ритм. Короткое предложение после длинного. Иногда одно слово отдельной строкой.

Конкретика вместо обобщений. Вместо «большие прослушивания» пишется «642 миллиона».

Живое слово там, где оно уместно. Канал про рэп. Отчёт для совета директоров никто не смотрит.

Прямое утверждение вместо обтекаемого. Если артист слабый, так и пишется.

Самое предсказуемое слово в предложении меняется на менее ожидаемое, но
уместное. Одна такая замена работает лучше трёх косметических правок.

## Что не работает

- Сервисы-гуманайзеры. Оптимизированы под обход детектора: меняют синонимы,
  ломают структуру. Детектор доволен, читать невозможно.
- Просьба «перепиши живее». Пустая формулировка, критериев в ней нет.
- Только убрать длинные тире. Необходимо, недостаточно.
- Вера детекторам. На русском они ошибаются в обе стороны.
- Чистка вместо содержания. Если внутри пусто, после чистки будет пусто.

## Автоматические проверки

Текстовые обороты ловит `build/lint.py` на каждом рендере:

```python
txt.count(chr(8212))                      # длинное тире, должен быть 0
re.findall(r', а не ', txt)               # должен быть пустой
re.findall(r'не [^.,!?]{2,40}, а ', txt)  # должен быть пустой
txt.count('не просто')                    # должен быть 0
```

Стоп-лист фраз гоняет `ops/slop.py` по декам и описаниям. Те же обороты по
всей документации гоняет `ops/selfcheck.py`. Описание проверяет
`ops/desclint.py`. Геометрию готового кадра проверяет `build/qa.py`.

Чекер `neXaY` обязателен. Он уже ловил реальные промахи: «не как дуэт, а», «Не артист, а один трек», «а не просто листать».

Одной командой всё сразу:

```bash
make check
```

## Структура выпуска

Семь кадров. Рабочий потолок по досмотру.

1. Хук с фото и вопросом, на который хочется ответить.
2. Конфликт или завязка.
3. Цифры, которые подтверждают или опровергают.
4. Формула или механика расчёта.
5. Результат с карточкой.
6. Контекст или таблица лиги.
7. Финальный вопрос и один призыв.

Один кадр равно одна мысль. Один выпуск равно одно действие зрителя.

Заготовка со всеми семью кадрами лежит в `build/decks/_template.json`.
Драматургия разобрана в `prompts/deck-logic.md`, механика площадки в
`ops/tiktok.md`, психология зрителя в `ops/audience.md`.
