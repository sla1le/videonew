# Правила текста

Аудитория пишет в комментариях «текст иишный». Каждый четвёртый зритель видит машину. Эти правила против этого.

## Запрещено абсолютно

| Что | Почему |
|---|---|
| Длинное тире | главный отпечаток машины |
| Эмодзи | то же самое |
| «не X, а Y» | самая узнаваемая схема |
| «X, а не Y» | зеркало предыдущей |
| «не просто» | то же семейство |
| Триады через запятую | искусственный ритм |
| Симметричные рубрики | читается как шаблон |
| Ровный ритм предложений | живой человек так не пишет |
| Корпоративные максимы в конце | пафос без содержания |
| Абстракция без конкретики | нечего проверить |
| Отсутствие «я» | у канала есть автор |

## Что делать вместо

Рваный ритм. Короткое предложение после длинного. Иногда одно слово отдельной строкой.

Конкретика вместо обобщений. Не «большие прослушивания», а «642 миллиона».

Живое слово там, где оно уместно. Канал про рэп, а не отчёт для совета директоров.

Прямое утверждение вместо обтекаемого. Если артист слабый, так и пишется.

## Автоматические проверки

Гонять на каждом рендере, реализованы в `build/qa.py`:

```python
txt.count(chr(8212))                      # длинное тире, должен быть 0
re.findall(r', а не ', txt)              # должен быть пустой
re.findall(r'не [^.,!?]{2,40}, а ', txt)  # должен быть пустой
txt.count('не просто')                  # должен быть 0
```

Чекер `neXaY` обязателен. Он уже ловил реальные промахи: «не как дуэт, а», «Не артист, а один трек», «а не просто листать».

## Структура выпуска

Семь кадров. Это рабочий потолок по досмотру.

1. Хук с фото и вопросом, на который хочется ответить.
2. Конфликт или завязка.
3. Цифры, которые подтверждают или опровергают.
4. Формула или механика расчёта.
5. Результат с карточкой.
6. Контекст или таблица лиги.
7. Финальный вопрос и один призыв.

Один кадр равно одна мысль. Один выпуск равно одно действие зрителя.

## Описание и хештеги

Описание до 3 000 знаков, пишется как продолжение разговора, а не как анонс.

Хештегов максимум пять. Пример рабочего набора:

```
#русскийрэп #скриптонит #лсп #pharaoh #эхо
```

## Имена

Официальное написание везде одинаковое. На одном кадре `PHARAOH`, на другом `Фараон` это ошибка.

## Самоконтроль

Фильтровать нужно не только слайды, но и прозу в чате. Запрещённые конструкции проскакивали именно там.
