# SVG-визуализации

`build/visuals.py` собирает графики и схемы как standalone SVG 936 на 640.
Файл кладётся в `build/img/` и дальше используется обычным кадром `photo`.
Основной рендер деки менять не требуется.

## Типы

- `radar`: профиль артиста по 3-6 осям, для ECHORATE обычно все шесть;
- `line`: динамика по времени, максимум четыре серии;
- `bar`: до восьми категорий;
- `timeline`: от двух до восьми событий;
- `quadrant`: до десяти объектов на двух осях.

Правила композиции и бюджета сложности лежат в `prompts/visual-system.md`.

## Radar

```json
{
  "title": "KIZARU / ICEGERGERT",
  "min": 30,
  "max": 99,
  "axes": ["ТЕКСТЫ", "ЗВУК", "ПОДАЧА", "ХИТЫ", "ЛАЙВЫ", "ВЛИЯНИЕ"],
  "series": [
    {"name": "KIZARU", "values": [86, 90, 88, 94, 70, 93]},
    {"name": "ICEGERGERT", "values": [74, 82, 89, 88, 83, 79]}
  ]
}
```

```bash
python3 build/visuals.py radar work/radar.json build/img/kizaru_ice_radar.svg
```

В деке:

```json
{
  "t": "photo",
  "h2": "ГДЕ У НИХ РАЗРЫВ",
  "img": "img/kizaru_ice_radar.svg"
}
```

## Line

```json
{
  "title": "OVR ПО ГОДАМ",
  "min": 30,
  "max": 99,
  "series": [
    {
      "name": "OVR",
      "points": [
        {"label": "2023", "value": 81},
        {"label": "2024", "value": 89, "show_label": true, "label_value": true},
        {"label": "2025", "value": 86},
        {"label": "2026", "value": 84}
      ]
    }
  ]
}
```

`show_label` включает подпись года у промежуточной точки. `label_value`
включает подпись самого значения.

## Bar

```json
{
  "title": "ОХВАТ ФОРМАТОВ",
  "items": [
    {"label": "ДУЭЛЬ", "value": 132000},
    {"label": "АЙСБЕРГ", "value": 60100},
    {"label": "СЕЗОН", "value": 43400}
  ],
  "accent": "ДУЭЛЬ"
}
```

`accent` принимает номер строки с нуля или точную подпись категории.

## Timeline

```json
{
  "title": "ТРИ ПЕРЕЛОМА",
  "items": [
    {"date": "2023", "title": "ВЫХОД"},
    {"date": "2024", "title": "ПИК"},
    {"date": "2026", "title": "СЕЙЧАС"}
  ]
}
```

События должны менять состояние истории. Служебный календарь в timeline
не переносится.

## Quadrant

```json
{
  "title": "ФОРМАТЫ ЭХО",
  "x_label": "ОХВАТ",
  "y_label": "ПОДПИСКА",
  "points": [
    {"label": "ДУЭЛЬ", "x": 90, "y": 55, "accent": true},
    {"label": "РАЗБОР", "x": 45, "y": 90},
    {"label": "АЙСБЕРГ", "x": 60, "y": 20}
  ]
}
```

Координаты `x` и `y` лежат в диапазоне 0-100. Это позиция на схеме, поэтому
входные значения заранее нормализуются из реальных метрик.

## Проверка

```bash
python3 build/visuals.py --self-test
```

Самотест строит все пять типов, парсит получившийся XML и проверяет размер
936 на 640.

## Ограничения

SVG использует только системные Arial и текущую палитру ECHORATE. Внешних
шрифтов, JavaScript и сетевых ресурсов нет.

Генератор отвечает за визуализацию данных. Он не решает, нужен ли график в
конкретном выпуске. Этот выбор делается по `prompts/visual-system.md`.
